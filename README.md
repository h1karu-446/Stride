# Stride

日々のタスク達成度・充実度・起床／就寝時刻を点数化して可視化する、自己改善向けのタスク分析アプリ。学習計画を立てると、その日にやるメニューが「今日」のタスクに自動で入る。

## 主な機能

画面は Today・Plans・Journey・Settings の4つ。

### Today（今日）

- **タスク**:
  - 日付ごとにタスクを登録し、重要度（重・中・軽）と時間帯を設定する。タイムラインで1日の予定を確認・編集できる
  - 削除したタスクは5秒間「元に戻す」で戻せる
- **計画との連動**:
  - 進行中の計画のメニュー（ルーティン）が、その日のタスクとして自動で入る。詳細は開いて読める
  - 期限を過ぎた予定は「今日に移す」で今日へ複製できる
- **振り返り**: 充実度（1〜5）、起床・就寝時刻、今日のハイライト、明日の意図、メモを記録する
- **スコア**: 1日を100点満点で採点し、A〜E のランクに分ける。A/B ランクの連続日数も表示する

  | 要素 | 配点 | 内容 |
  | --- | --- | --- |
  | 完了 | 80 | 重要度で重み付けしたタスクの完了率 |
  | 充実 | 5 | 充実度（1〜5） |
  | 起床 | 7.5 | 目標起床時刻からの遅れで減点（150分遅れで0点） |
  | 就寝 | 7.5 | 目標就寝時刻からの遅れで減点（150分遅れで0点） |

### Plans（学習計画）

- **計画**: 色・状態（構想中・進行中・休止中・完了）・期日を持つ
- **計画の詳細**:
  - 計画名・期日・到達目標・目指す姿（箇条書き）を、表示された場所でそのまま編集できる
  - 一番下に、Markdown で自由に書ける「概要」欄がある
- **フェーズ**:
  - 期間を区切ったフェーズをタイムラインで表示する
  - 帯のドラッグで期間を移動・調整し、空いている所のドラッグで新しいフェーズを追加する。期間の重なりも可
  - 予定より早く終えたら「完了にする」で完了日を記録する。予定の期間は残る
- **メニュー**: フェーズごとに、所要時間・曜日・重要度・詳細を決めた繰り返しのメニューを置く。Today のタスクはここから作られる
- **予定と教材**:
  - 単発の予定（マイルストーンを含む）を登録できる
  - 予定はフェーズのタイムラインにも日付の位置に印（マイルストーンは ◆）で表示され、印を押すと内容を確認できる
  - 教材ごとに、リンク・メモ・状態（未着手／使用中／完了）・関連するフェーズを管理する
- **削除の取り消し**: 計画・フェーズ・メニュー・予定・教材の削除は、直後なら「元に戻す」で戻せる

### Journey（振り返り）

- **カレンダー**: 過去のスコアとランクを月ごとに俯瞰する（旧 `/calendar` は `/journey` へ移動）
- **やりたいこと**: 重要度を付けて登録し、達成したら達成日を記録する
- **達成の記録**:
  - 達成したやりたいこと・完了した計画・マイルストーン・教材を時系列にまとめる
  - 全画面のスクロール表示で振り返れる

### Settings（設定）

既定の目標起床・就寝時刻、パスワード変更、登録済みのタスク数と振り返りの数。

## 必要なもの

- Node.js 24 と npm（React 18・TypeScript 5・Vite 8・Tailwind CSS 3。テストは Vitest 5）
- Supabase（認証とデータベース）。検証用はDocker上のローカル環境を使用
- ローカル検証にはDockerとSupabase CLI

## セットアップ

```sh
npm install
test -e .env.local || cp .env.example .env.local
```

`.env.local` に Supabase の `VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` を設定し、`supabase/migrations/` のスキーマを番号順に Supabase に適用する。migration は追記のみで、各 migration の検証SQLは `supabase/tests/` にある。

既存の `.env.local` は保持する。Docker上のSupabaseの起動、DB権限の設定、接続先の切り替えは [プロジェクト固有Context](docs/project-context.md#ローカル検証環境issue-5) を参照する。

## 起動と使い方

```sh
npm run dev
```

表示されたURLを開き、メールアドレスとパスワードでサインアップ・サインインする。「今日」画面でタスクと振り返りを記録すると、スコアが計算される。
