# ADR（Architecture Decision Record）

設計上の判断を、1件につき1ファイルで記録する。「何を決めたか」だけでなく、「なぜそう決めたか」「他の案をなぜ選ばなかったか」を残す。

## 運用ルール

- ファイル名は `NNNN-短い英語名.md`（連番は4桁）
- 一度承認したADRは書き換えない。判断を変えるときは新しいADRを書き、古い方のステータスを「置き換え済み（ADR-NNNNで置き換え）」にする
- 誤字や、判断に影響しないリンクの修正は書き換えてよい

## テンプレート

```markdown
# ADR-NNNN: タイトル（決めたことを一言で）

| 項目 | 内容 |
| --- | --- |
| ステータス | 提案中 / 承認済み / 置き換え済み（ADR-NNNNで置き換え） |
| 日付 | YYYY-MM-DD |
| 関連 | 関連する文書へのリンク |

## 状況
何に困っていて、何を決める必要があったか。

## 決定
どうすることにしたか。

## 検討した案
| 案 | 概要 | 評価 |
| --- | --- | --- |

## 影響
- 良くなること
- 引き受けるデメリットと、その対処
```
